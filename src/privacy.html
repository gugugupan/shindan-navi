取得する情報と利用目的

サイトを閲覧したとき

本サイトは Cloudflare, Inc.（米国）のサービスで配信しています。ページを表示する際、IP アドレス、ブラウザの種類、閲覧した URL、日時などの通信情報が Cloudflare に送られ、配信・キャッシュ・不正アクセスや過剰なアクセスの防止（アクセス回数の制限）のために処理されます。運営者は、利用者を識別する目的でこれらの通信情報を独自に記録・保存していません。

イベントカレンダー（/events/）を初めて開いたときは、接続元 IP アドレスから Cloudflare が推定した都道府県を初期表示に使います。位置情報の許可は求めず、推定結果を本サイトが保存することもありません。

アクセス解析（Google アナリティクス）

サイトの利用状況を把握して改善するため、Google LLC（米国）の Google アナリティクス 4 を利用しています（本サイトのドメイン shindan-navi.app で表示した場合のみ）。Google アナリティクスは Cookie を使い、閲覧したページ、参照元、端末・ブラウザの情報、おおよその地域のほか、本サイト上の操作（選んだタイトルや都道府県、表示の切り替え、お気に入り登録した商品名、カレンダー追加など）を Google に送信します。ログイン中であっても、アカウントの ID やメールアドレスを Google アナリティクスに送信することはありません。ログイン・ログアウト・アカウント削除については、その操作をしたという事実（操作の種類）のみを送信します。

Google によるデータの取り扱いは Google のサービスを使用するサイトやアプリから収集した情報の Google による使用 をご覧ください。送信を止めたい場合は、Google アナリティクス オプトアウト アドオン の利用やブラウザの Cookie 設定で無効にできます。

Google アカウントでのログイン

Google アカウントでログインすると、Google から次の情報を受け取り、保存します。

  • Google アカウントの識別子（sub）
  • メールアドレス（Google で確認済みのもの）
  • 表示名
  • プロフィール画像の URL

あわせて、ログイン中に同期するお気に入り・イベントカレンダーの絞り込み条件（選んだ都道府県を含む）・カレンダー追加確認の設定、ログイン状態を保つためのセッション情報（セッション ID のハッシュ値と有効期限）、利用プラン（現在はすべて無料）、各データの作成・更新日時を保存します。

利用目的は、ログインと本人の確認、お気に入りや設定を複数の端末・ブラウザで同期すること、不正な利用の防止、お問い合わせへの対応です。Google のパスワードや、Google のアクセストークン・リフレッシュトークンは受け取らず、保存もしません。Google ドライブやカレンダーなど、ほかの Google のデータにアクセスすることもありません。

これらの情報は、Cloudflare が提供するデータベース（Cloudflare D1）に保存します。データは米国その他の国にある Cloudflare のデータセンターで保管される場合があります。

プロフィール画像は、表示するときに利用者のブラウザが Google のサーバーから直接読み込みます（リファラーは送信しません）。

ご意見・ご要望フォーム

ご意見・ご要望フォーム（/feedback/）から送信すると、次の情報を受け取り、保存します。

  • 種類（不具合・要望・データの誤り・その他）と、入力された内容
  • 返信先メールアドレス（入力した場合のみ）
  • フォームを開く前に見ていたページの URL（送信元ページ）
  • ログイン中に送信した場合は、アカウントの ID
  • 受付日時と、運営者への通知メールを送信できたかどうか

利用目的は、ご意見への対応と本サイトの改善、不具合やデータの誤りの修正、メールアドレスを入力した場合の返信です。メールアドレスを返信以外の目的（お知らせの送信など）に使うことはありません。

スパムなどの不正な送信を防ぐため、Cloudflare, Inc.（米国）の Cloudflare Turnstile を使っています。フォームを開くと、Turnstile が端末・ブラウザの情報や IP アドレスなどを Cloudflare に送信し、人による操作かどうかを確認します。送信時の IP アドレスは、この確認と短時間の送信回数の制限のためにその場で利用するだけで、本サイトでは保存しません。

送信された内容は Cloudflare D1 に保存し、あわせて Cloudflare のメール配信機能（Email Routing）で運営者のメールアドレスに通知します。

話題カレンダー

話題カレンダー（/voices/）は、X（旧Twitter）で公開されている投稿をもとに、タイトルごとの話題を AI で要約して掲載しています。本サイトが保存・掲載するのは、運営者側で作成した要約・意見の言い換えと、もとになった公開投稿へのリンクだけです。投稿の本文や画像、投稿者のプロフィールなどは保存・転載しません。ただし、X の投稿のリンク（URL）には投稿者のアカウント名（ユーザー名）が含まれます。要約・意見の言い換えは話題全体をまとめたもので、特定の投稿者の発言として掲載するものではありません。

ご自身の投稿へのリンクや、その投稿にもとづく掲載内容の削除をご希望の場合は、1 のお問い合わせ先までご連絡ください。確認のうえ、公開サイトから削除します。なお、本サイトのソースコードを公開している GitHub リポジトリの変更履歴には、削除前のデータファイルが残る場合があります。このページを閲覧しても、閲覧者の情報が X に送信されることはありません（投稿へのリンクを開いた場合を除きます）。

第三者への提供と委託

取得した個人情報を販売したり、法令に基づく場合を除いて本人の同意なく第三者に提供したりすることはありません。

本サイトの運営に必要な範囲で、配信・データ保存・フォームのスパム防止・通知メールの配信を Cloudflare, Inc.（米国）に、ログイン認証を Google LLC（米国）に、アクセス解析を Google LLC（米国）に委ねています。米国には日本の個人情報保護法に相当する連邦レベルの包括的な個人情報保護法はなく、州法（カリフォルニア州消費者プライバシー法など）や分野ごとの法律によって保護されています。各国の制度については 個人情報保護委員会の調査結果 をご覧ください。各社は個人情報の保護に関する方針を公表し、セキュリティ対策を行っています。

保存期間と削除

  • アカウントの情報（2-4）は、アカウントを削除するまで保存します。
  • セッション情報は、ログアウトしたときに削除します。有効期限（180 日）を過ぎたものと、同じアカウントで新しい順に 10 件を超えたものは、次にログインしたときに削除します。
  • 設定画面の「アカウントを削除」から、いつでもアカウントを削除できます。削除すると、アカウント・連携した Google アカウントの情報・同期したお気に入りと設定・セッションをデータベースからすぐに完全に削除します（ブラウザの localStorage に残っているお気に入り等は消えません）。フォームから送信したご意見は残り、アカウントとの紐付け（アカウントの ID）だけを削除します。
  • ご意見・ご要望フォームから送信された内容は、受付から 1 年間保存し、1 年を過ぎたものは順次削除します。期間内でも、1 のお問い合わせ先にご連絡いただければ削除します。運営者に届いた通知メールは、ご意見への対応に必要な間だけ保管し、不要になったものは削除します。
  • Cloudflare D1 の障害復旧機能（Time Travel）により、削除後も一定期間（Cloudflare の契約プランに応じて 7 日間または 30 日間、最大 30 日間）、復元用のデータが Cloudflare のシステム内に残る場合があります。運営者がこれを通常の業務で利用することはありません。

安全管理のための措置

  • 通信はすべて HTTPS で暗号化しています。
  • ログイン用の Cookie は JavaScript から読み取れない設定とし、セッション ID はハッシュ値のみを保存しています。
  • データベースや管理画面へのアクセスは運営者に限定し、認証用の鍵は公開しない方法で管理しています。
  • 保存する情報は、2-4 に挙げたものに限っています。
  • 利用状況に応じて、外部サービスの安全管理の状況を確認します。
